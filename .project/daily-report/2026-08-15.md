# 開発日誌

日付：2026-08-15

## 作業内容

- ネジ抜きパズルの可視判定・合法手・ヒント・解法探索を共有ゲームエンジンへ集約した。
- 隠れたネジの非表示、手詰まり時のUndo誘導、44pxの穴タップ領域、ネジ回転と板落下時の振動を追加した。
- ステージ選択、段階解放、基準手数による星評価、ベスト手数、保存形式の移行を実装した。
- 16面の手作りステージを追加し、各面の解法を一手ずつ再生して合法性とクリアを検証した。
- Claude Codeレビューで見つかった保存・星評価の不整合を修正した。

## 次回の予定
