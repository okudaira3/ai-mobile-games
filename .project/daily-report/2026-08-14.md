# 開発日誌

日付：2026-08-14

## 作業内容

- ネジ抜きパズルを実装し、ゲーム一覧からプレイできるようにした。
- ネジを選択して空き穴へ移動し、板のネジがすべて外れると重力で落下するルールを実装した。
- 盤面の重なり順、クリア演出、Undo、途中保存、レベル進行を追加した。
- UIを Water Sort Lab のダーク実験室テーマへ統一しつつ、ネジ盤自体はフラットなカジュアルパズル調に調整した。
- Claude Code と相談し、元のネジ穴を移動先に使えるルールを維持したまま、レベル別の予備穴数と交差ロックで難易度を作る方針に決定した。
- 予備穴をレベルごとのデータに変更し、レベル1〜2は2穴、レベル3は1穴に調整した。隠れるべきネジ・穴の重なり判定も修正した。

## 次回の予定

- 各レベルを通して解き、交差ロックによる難易度が公平か確認する。
- 循環依存を使ったレベル4・5と、著者解に基づくヒントを設計する。
- GitHub Pages公開後のスマホ表示とクリア演出を確認する。

## 感想

ネジを外した板が一拍置いてから落下するようになり、静止画よりもゲームらしい手触りが出た。難易度は空き穴を減らすだけでは足りず、どの穴がいつ見えるかを設計する必要があると分かった。
